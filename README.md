# E-Catalog Flipbook V4 — Cover + Double Spreads

10 pages: cover **1** alone, inside spreads **2–3**, **4–5**, **6–7**, **8–9**, back cover **10** alone on desktop. On narrow mobile screens the library switches to one page at a time.

Uses StPageFlip `showCover: true`, realistic curl and shadows. Next/Previous now use the library’s spread-aware `flipNext()` / `flipPrev()` so they turn an entire spread. Page selector jumps to a specific page.

Upload **the contents of this ZIP**, not the enclosing folder, to the root of your GitHub Pages repository. Replace `assets/pages/page-01.jpg` through `page-10.jpg` with your images or edit `config.js` paths. Keep the page count even for front/back cover pairing. The page-flip engine is loaded from CDN and needs an internet connection. If unavailable, a single-page fallback is shown.
