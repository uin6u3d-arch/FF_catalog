# Modern E-Catalog — 10-page test

This is a ready-to-upload GitHub Pages demo with 10 JPG pages numbered 1–10.

## Publish
1. Create a public GitHub repository.
2. Upload the **contents** of this folder to the repository root.
3. In Settings > Pages, select Deploy from a branch, main, /(root).
4. Open https://YOUR-USERNAME.github.io/YOUR-REPO/ once deployed.

## Change pages
Replace JPG files under `assets/pages/` and update the ordered `pages` list in `config.js`. PNG is also supported.

## Controls
Previous / Next, page selector, keyboard arrows, swipe on touchscreens, zoom, fullscreen. Desktop displays cover alone then two-page spreads; mobile displays one page.
